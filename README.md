# Bioinformatics Tools
Bioinformatics utilities package
Привет!
Это набор простых биоинформатических утилит на Python. 

Здесь собраны инструменты, которые помогают работать с популярными биологическими форматами файлов: FASTQ,FASTА и BLAST. 
#Структура проекта
bioinformatics_tools/
├── README.md # вы сейчас здесь
├── main.py # главный скрипт
└── helpers/
    ├── init.py
    ├── fastq.py # вспомогательные функции для FASTQ
    └── bio_files.py # вспомогательные функции для FASTA и BLAST

#Что умеет?
1. Фильтрация FASTQ - функция `filter_fastq` фильтрует риды по GC-составу, длине и среднему качеству (шкала Phred+33). Фильтрация идёт на лету, так что можно работать с огромными файлами без проблем с памятью. Отфильтрованные риды сохраняются в папку `filtered/`.
2. Преобразование FASTA - функция `convert_multiline_fasta_to_oneline` собирает многострочные последовательности в одну строку. Если выходной файл не указан, создаётся автоматически с суффиксом `oneline`.
3. Парсинг BLAST - функция `parse_blast_output` достаёт первое (лучшее) совпадение для каждого запроса из результатов BLAST, сортирует по алфавиту и сохраняет в один файл.

#Как использовать?
Все функции импортируются из "main.py" или напрямую из "helpers/". Пример:
#python
from main import filter_fastq
filter_fastq("input.fastq", "output.fastq", gc_bounds=(40, 60), quality_threshold=30)
